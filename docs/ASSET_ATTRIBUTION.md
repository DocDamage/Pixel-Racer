# Asset Attribution and Release Packaging Notes

Pixel Track Works is built around the **Wheels in Pixels Racing Asset Pack** by **N3 Cloud** and preserves the original repository's vehicle, bike, environment, track, VFX, web/config, and authored vehicle-data content.

Original pack page referenced by the project design:

`https://n3cloud.itch.io/wheels-in-pixels-racing-asset-pack`

## Release rule

This document is attribution context, **not a substitute for the asset pack's license or distribution terms**.

Before publishing a production release, the release owner must verify the exact license/redistribution terms that apply to the source pack and include any license/credit files required by those terms.

Do not add invented license language or claim broader redistribution rights than the source license provides.

## Project-created/runtime content

The Godot implementation adds code/data for systems including track construction, racing, AI, Garage/Career progression, procedural generation, ghosts, sharing, persistence recovery, accessibility, audio/VFX, and modular character/dialogue presentation.
